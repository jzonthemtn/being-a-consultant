# Going Independent

Guest lecture on being an independent consultant, for a college AI consulting class (September 30, 2026).

- `going-independent.pptx` — the slide deck (12 slides, with speaker notes)
- `going-independent.pdf` — PDF export for backup/sharing
- `build.js` — script that generates the deck

## Rebuilding

```sh
npm install
npm run build
soffice --headless --convert-to pdf going-independent.pptx
```
